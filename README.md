PhonePe Transaction Analysis Dashboard
Project Overview
This project analyzes PhonePe transaction data to understand transaction performance, payment trends, cashback distribution, customer activity, and potential fraudulent transactions. An interactive dashboard presents key metrics and visual insights to support data-driven decision-making.

Dashboard Features
1. Transaction Analysis Over Time
•	Daily transaction amount trends.
•	Hourly transaction activity.
•	Transaction patterns across different days of the week.
2. UPI Application Analysis
•	Transaction distribution across PhonePe, Google Pay, Paytm, Amazon Pay, BHIM, and other UPI applications.
•	Comparison of payment application usage.
3. Transaction Status Analysis
•	Successful transactions.
•	Refunded transactions.
•	Pending transactions.
•	Failed transactions.
4. State-wise Analysis
•	Geographic distribution of transaction amounts across Indian states.
•	Comparison of transaction performance between states.
5. Bank-wise Analysis
•	Transaction amount comparison across banks.
•	Identification of banks with higher transaction volumes by value.
6. Transaction Type Analysis
•	Wallet transfers.
•	Subscriptions.
•	Recharges.
•	Online shopping.
•	Bill payments.
•	P2P and P2M transactions.
7. Interactive Filters
The dashboard includes filters for:
•	State
•	Gender
•	Merchant category
These filters allow users to explore different segments of the transaction data.
Tools & Technologies
•	Microsoft Excel — Dashboard creation, data visualization, and interactive filtering.
•	Data Analysis — KPI reporting, trend analysis, and category-wise comparisons.
•	Git & Github — Version controlling and Hosting
Conclusion
This project demonstrates practical data analysis and dashboard development skills using transaction data. It combines KPI tracking, time-based analysis, geographic comparisons, payment application analysis, and interactive filtering in a single dashboard .
